# יורוליג 2026/27 – דף תחזית PIR אינטראקטיבי

הדף מתעדכן אוטומטית **12 שעות אחרי סיום כל מחזור**. בעדכון רץ רק החיזוי (`run_euroleague_next_round`). האימון לא רץ: הוא משתמש בקובץ `output/EuroLeague_historical_models_2024_2026_v11.rds`.

## מבנה התיקייה
```
R/            הסקריפטים המקוריים (ללא שינוי) + 2 חדשים:
              EuroLeague_web_export_v11.R   – בונה את הדף מתוך הפלטים
              EuroLeague_auto_update_v11.R  – בודק אם עברו 12 שעות מסוף מחזור, מריץ ומעדכן
web/template.html   תבנית הדף
output/       תיקיית הפלט (NEW), כולל קובץ המודל המאומן
docs/         הדף עצמו: index.html (עצמאי לגמרי) + data.json + state.json
.github/workflows/update-site.yml   ההרצה האוטומטית
run_update_windows.bat              חלופה: הרצה ממחשב Windows
```

## אפשרות א' – GitHub (מומלץ, לא צריך מחשב דולק)
1. יוצרים ריפו **ציבורי** חדש ב-GitHub. (GitHub Pages בחינם דורש ריפו ציבורי.) מעלים אליו את כל התיקייה.
2. בריפו נכנסים ל-**Settings → Pages**. ב-Source בוחרים `Deploy from a branch`, ואז `main` ותיקיית `/docs`.
3. ב-**Settings → Actions → General** מסמנים `Read and write permissions`.
4. הדף יהיה זמין בכתובת `https://<user>.github.io/<repo>/`.
5. כדי לבדוק מיד: **Actions → EuroLeague round update → Run workflow**, ומסמנים `force`.

ה-workflow רץ כל שעה, ובשעות המשחקים (16:00–23:00 UTC) כל 10 דקות. בריפו ציבורי זה בחינם:
* הוא מוריד רק את לוח המשחקים ומוצא את המחזור האחרון שכל משחקיו שוחקו.
* סוף המחזור = שעת הפתיחה של המשחק האחרון + 2.5 שעות. אם עברו 12 שעות מאז והמחזור עוד לא פורסם (`docs/state.json`), הוא מריץ את החיזוי, בונה את הדף מחדש ועושה commit.
* אם ה-box scores עוד לא זמינים ב-API, הוא ינסה שוב בשעה הבאה, עד 24 שעות.
* **בכל הרצה** (`EuroLeague_live_v11.R`) מתעדכן `docs/live.json`, בלי לגעת בתחזית:
  * תוצאות אמת של משחקי המחזור שהסתיימו: PIR, דקות ודירוג אמיתי מתוך כל מי ששיחק.
  * נתונים חיים של משחקים שבזמן אמת מתקיימים.
  * טבלת היריבות לפי עמדה, כולל משחקים שהסתיימו.
  * המשחק הבא של כל קבוצה.

  ההורדה הכבדה רצה רק כשמשחק חדש הסתיים, וה-commit נוצר רק כשמשהו השתנה. הדף פתוח בדפדפן? הוא טוען את `live.json` מחדש כל 5 דקות.

## אפשרות ב' – מחשב Windows / כונן רשת
1. מעדכנים את הנתיבים ואת נתיב `Rscript.exe` בקובץ `run_update_windows.bat`.
2. ב-Task Scheduler יוצרים משימה שמריצה את הקובץ כל שעה.
3. פותחים את `index.html` מתיקיית `EL_SITE_DIR`. הקובץ עצמאי ולכן עובד גם מכונן רשת.

## הרצה ידנית
```
Rscript R/EuroLeague_auto_update_v11.R           # רק אם הגיע הזמן
Rscript R/EuroLeague_auto_update_v11.R --force   # עכשיו
```
משתני סביבה אופציונליים: `EL_OUTPUT_DIR`, `EL_SITE_DIR`, `EL_DELAY_HOURS` (ברירת מחדל 12), `EL_GAME_HOURS` (ברירת מחדל 2.5).

## מה בדף
* **טופ 15**: 15 המובילים בסקור בכל אחד משני המודלים.
* **לוח המחזור הקרוב**: שעות לפי שעון ישראל, והשחקן המוביל בכל קבוצה.
* **חיפוש שחקן**: השלמה אוטומטית שמציגה שם מלא, קבוצה ועמדה. לכל מודל מוצגים Score, דירוג, PIR צפוי וטווח, והרכיבים שבונים את הסקור עם המשקלים והנוסחה המלאה. מוצגת גם היריבה הקרובה.
* **השוואה**: עד 4 שחקנים, והערך הטוב ביותר בכל שורה מודגש. אפשר לשתף קישור, למשל `#search/1,4,2`.

**PIR צפוי:** הסקור הוא מדד לדירוג. כדי לתרגם אותו ל-PIR מתאימים רגרסיה `PIR ≈ a + b·Score` על תוצאות האמת של מחזורי 2026/27 (מבחן מחוץ למדגם, שחקנים ששיחקו לפחות דקה). הכיול מתעדכן בכל מחזור. הטווח מכסה 80% מהשאריות.

**שחקן לא מדורג** (פחות מ-5 הופעות, פחות מ-10 דקות בממוצע, או קבוצה בלי משחק במחזור): הוא עדיין מופיע בחיפוש עם הנתונים שלו וסיבת אי-הדירוג.
